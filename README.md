# Rich Click

Русскоязычная браузерная игра-кликер с бизнесом, недвижимостью, автомобилями и коллекцией раритетов.

## Запуск
Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## Публикация
В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** как источник. Workflow автоматически публикует сайт при push в `main`.

## Важно о текущей версии
Это автономная демоверсия: игровой прогресс хранится в localStorage браузера. Глобальные аккаунты, синхронизация между устройствами и общий TOP-100 требуют отдельного серверного backend/API. GitHub Pages — статический хостинг и сам по себе не предоставляет базу данных или авторизацию.
